# E-Commerce Sales Analysis Using SQL

## Project Overview
This project analyzes e-commerce sales data using Microsoft SQL Server.

The goal was to identify sales performance, regional trends, product performance, category performance, and monthly sales patterns.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## SQL Skills Demonstrated
- SELECT
- SUM
- AVG
- COUNT
- GROUP BY
- ORDER BY
- WHERE
- TOP
- YEAR()
- MONTH()
- Aggregate analysis

## Business Questions
1. What is the overall sales performance?
2. Which region generates the most revenue?
3. Which product category generates the most revenue?
4. What are the top 5 products by revenue?
5. How do sales change month by month?
6. What is the average order value by region?
7. Which orders are considered high-value?

## Key Insights

- The East region generated the highest revenue at $2,290.
- Electronics was the strongest product category with $3,810 in sales.
- Laptops were the highest-performing product with $1,900 in revenue.
- March had the highest monthly sales at $2,260.
- February had the lowest monthly sales at $1,175.

## Conclusion
The analysis shows that electronics and laptop products are major revenue drivers. The East region performed best, and monthly sales increased strongly in March after a weaker February.
