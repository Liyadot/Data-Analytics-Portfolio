# Sales Performance Dashboard — Power BI

## Project Overview

This Power BI project analyzes sales performance and presents key business metrics in an interactive dashboard.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data modeling
- Data visualization

## Key Analysis

- Total sales performance
- Profit and profitability trends
- Sales comparison across business categories
- Performance changes over time
- Interactive filtering for deeper analysis

## Dashboard Features

- Key performance indicators (KPIs)
- Interactive charts and visuals
- Filters and slicers
- Data relationships and calculated measures
